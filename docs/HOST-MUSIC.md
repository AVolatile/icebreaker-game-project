# Demo host music

`src/lib/music.ts` owns one lazily created `HTMLAudioElement`, scoped to
`HostRoom`. The existing sound button and M shortcut control music and the
unchanged `src/lib/sound.ts` host effects. Sound starts off. Unmuting calls
`play()` directly inside the host gesture; rejected playback is swallowed.
Toggle sound off/on to retry if the browser blocks playback.

Lobby, intro, results and intermission use their named tracks. Active and voting
use the current Original's track; final uses finale. Repeated room updates and
active → voting keep the same playback position. Mute pauses music and unmute
resumes it. Track changes have a 180 ms fade-in at a background volume of 18%.
Ended rooms, invalid host sessions and unmount stop and release the media.
Player and participant pages never create this controller. No socket audio
state, server synchronization, providers or production audio engine are used.

## Assets

The eleven hashed MP3 files in `public/audio/` were copied byte-for-byte from
`production/main` of `AVolatile/ruckus-development`, commit
`311a607ab57e6eac466e54e731cd88fe1936c87b`. MP3 keeps the single-element controller
compatible with desktop host browsers without codec selection infrastructure.
`tests/music.test.ts` verifies the content hashes in their filenames.

Production's `audio/ASSET-PROVENANCE.md` and `audio/assets.json` describe these as
project-owned original procedural output, generated by `ruckus-procedural-v1`
on 2026-10-15 with no imported recordings, compositions or samples. They retain
their **pre-release-reference** classification and `productionApproved: false`;
copying them here does not change that approval status. No open redistribution
license is granted. The original provenance document remains in production.

## Verification

Run `npm run typecheck`, `npm test` and `npm run build`. With the app running on
port 4310, run `npx playwright test tests/browser/music.spec.ts` for real-media
playback, host controls, phase transitions, participant isolation, cleanup and
blocked/unavailable playback coverage. Physical conference-room speaker levels
and subjective listening should be checked on the equipment used for the pilot.
